# Imagery and prompt

Generate a consistent 14-glyph set identifying each skill’s job. Individual SVG files and their prompts are in assets. The single featured result uses the existing 3.5 percent Monday share, 1,215 rows and 9 skipped rows, for 1 October–31 December 2025.

All new illustrations were generated locally as SVG code. Original vector artwork is dedicated to CC0 1.0. The Scholar map boundaries are Natural Earth public domain, inherited from round 2. There is no raster artwork. SVG controls are functional icons.
