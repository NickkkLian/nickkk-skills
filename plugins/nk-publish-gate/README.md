# nk-publish-gate (Codex plugin)

A privacy gate to run before anything goes public (a repo, a release zip, a demo folder, a PDF): it finds what is private but is not a secret, such as a home-directory path inside an xlsx, a username in a .pyc or a personal address in the commit history.

Generated copy of [NickkkLian/nk-publish-gate](https://github.com/NickkkLian/nk-publish-gate) in the plugin layout OpenAI Codex reads (`skills/nk-publish-gate/SKILL.md`). The skill's README, compatibility notes and history are in that repository. Install: `codex plugin marketplace add NickkkLian/nickkk-skills` then `codex plugin add nk-publish-gate@nickkk-skills`.
