# The seven invariants (a page that breaks one is not in the family)

| # | Invariant | Why this one |
|---|---|---|
| 1 | Top bar anatomy is fixed, on the deep anchor band: mark → product name → one-line positioning (with its guard clause; it truncates first when the bar is narrow) → `Demo ·` pill → flexible space → light/dark toggle → source link | it is what a visitor looks at in the first seconds; the same structure makes the second product free to learn |
| 2 | The mark is built by a construction rule (24×24: rounded cell, a "seal" filled with the point colour in the top-right, one to three strokes for the product), never drawn as a picture | a rule survives new products and dark mode; a picture does not |
| 3 | The first screen opens on the signature plate: an anchor-coloured panel with the page title, a one-paragraph lede and the reconciliation bar — a segmented bar, a legend and a monospace equation computed from the loaded data (`114 + 3 + 8 = 125 ✓`); the "unknown" segment is hatched and stays out of the equation | numbers that add up are more convincing than any claim, and the plate puts them where the eye lands first |
| 4 | Every derived value carries a provenance chip (`src A:6`, `rule exact alias`, `rev 2`) | the promise "every row traceable" has to be visible, not written in the README |
| 5 | Status vocabulary is fixed and shared across products: Needs review · Approved / Booked / Sent · Rejected / Failed · Draft · Simulated · Excluded · Blocked — each with a second channel beside the colour (dot, ✓ or ⊘) | one word, one colour, one meaning everywhere; colour alone is not enough (WCAG 1.4.1, use of colour) |
| 6 | The honesty block is fixed: `Demo · synthetic data` in the top bar, and a footer on the anchor band with About this demo / Not verified here / Source | the interface has to back the author's claim of knowing what was and was not checked |
| 7 | One token file and one appearance contract: semantic tokens only; `data-theme` picks the palette and `data-scheme` picks light or dark, set by a head script before first paint; the defaults write no attribute | the cheapest consistency there is; the head script is what keeps a saved choice from flashing the default first |

The signature (where boldness is spent) is "evidence visible": the plate with its reconciliation bar,
the chips, the hatched unknown. It cannot be copied by choosing a louder colour; only a product that
reconciles and traces its data can show it.
