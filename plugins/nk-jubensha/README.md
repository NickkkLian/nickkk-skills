# nk-jubensha (Codex plugin)

Build a playable jubensha (剧本杀, the Chinese murder-mystery party game) from a premise - a cast, a trick chosen from an abstract taxonomy, a clue chain in which every deduction stands on a clue some player actually receives, and printable HTML booklets (one per player, clue cards, a host handbook).

Generated copy of [NickkkLian/nk-jubensha](https://github.com/NickkkLian/nk-jubensha) in the plugin layout OpenAI Codex reads (`skills/nk-jubensha/SKILL.md`). The skill's README, compatibility notes and history are in that repository. Install: `codex plugin marketplace add NickkkLian/nickkk-skills` then `codex plugin add nk-jubensha@nickkk-skills`.
