# nk-deck (Codex plugin)

Turn one sentence — a topic and who it is for — into a ten-slide HTML deck whose titles carry the argument on their own, five points at most per slide, a source under every number, and a printout that is the same deck page for page.

Generated copy of [NickkkLian/nk-deck](https://github.com/NickkkLian/nk-deck) in the plugin layout OpenAI Codex reads (`skills/nk-deck/SKILL.md`). The skill's README, compatibility notes and history are in that repository. Install: `codex plugin marketplace add NickkkLian/nickkk-skills` then `codex plugin add nk-deck@nickkk-skills`.
