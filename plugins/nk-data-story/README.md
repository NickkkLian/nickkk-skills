# nk-data-story (Codex plugin)

Turn a CSV or Excel file into a one-page data report whose headline is the conclusion and where every figure states its denominator, window and filter.

Generated copy of [NickkkLian/nk-data-story](https://github.com/NickkkLian/nk-data-story) in the plugin layout OpenAI Codex reads (`skills/nk-data-story/SKILL.md`). The skill's README, compatibility notes and history are in that repository. Install: `codex plugin marketplace add NickkkLian/nickkk-skills` then `codex plugin add nk-data-story@nickkk-skills`.
